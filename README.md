
# W2GG: Weak-to-Glance Guidance for Weakly Supervised Video Moment Retrieval

Official implementation of W2GG.

## Overview

W2GG generates reliable pseudo-glance guidance
from weak video-query supervision without manual
temporal annotations.

## Framework

- Pseudo-Glance Discovery (PGD)
- Pseudo-Glance Supervision (PGS)
- Multi-Glance Learning (MGL)

## Code Structure

- `aks/`: Modified AKS implementation for PGD
- `w2gg/`: W2GG model implementation
- `configs/`: Experiment configurations
- `scripts/`: Training and evaluation scripts
